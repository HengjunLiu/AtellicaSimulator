# Atellica Solution Simulator

## 概述

Atellica Solution Simulator 是一个精确模拟西门子医疗检验设备 Atellica Solution 核心功能的模拟器。该模拟器能够与实验室自动化系统(LAS)和医院实验室信息系统(LIS)进行数据交互，支持有UI和无UI两种运行模式，适用于系统集成测试和开发环境。

## 功能特性

### 数据交互功能
- **LAS 通信**：支持与实验室自动化系统(LAS)的 TCP/IP 通讯，采用 uRAP 协议
  - 支持Handshake握手协议
  - 支持仪器健康状态查询
  - 支持测试项目库存查询
  - 支持在线样本信息管理
  - 支持装载/卸载请求处理
  - 支持队列管理（添加、跳过、清除）
- **LIS 通信**：支持与医院实验室信息系统(LIS)的 TCP/IP 通讯，采用 ASTM 协议
  - 支持标本工单查询
  - 支持测试结果自动发送
  - 支持患者信息接收
- **样本处理**：完整的样本生命周期管理
  - 接收LAS运送标本
  - 查询LIS获取测试工单
  - 自动生成随机测试结果
  - 结果自动回传LIS
  - 支持手工弹出标本

### 用户界面
- 显示模拟器关键运行参数
  - 自动化接口状态
  - 仪器处理状态
  - LIS连接状态
  - 在线试管数量
  - 已完成试管数量
  - 队列状态信息
- 支持手动修改仪器运行状况参数
- 独立的 LAS 和 LIS 通讯日志显示区域
- 日志显示优化：仅显示实时日志，限制500行，提高性能
- **在机标本管理**：
  - 查看当前在线标本列表
  - 支持手工弹出标本
  - 实时刷新标本状态
- **库存编辑**：
  - 编辑测试项目库存
  - 编辑耗材库存
- **LIS模拟**：模拟LIS发送工单数据

### 运行模式
- **有UI模式**：完整的图形用户界面，支持人工操作和监控
- **无UI模式**：命令行/后台运行模式，支持自动执行测试案例

### 日志管理
- 每日自动生成新的日志文件
- 日志文件命名格式：`XXXXXXXX-YYYY-MM-DD.log`
- 支持日志文件自动轮换，默认保留7天日志
- 日志文件自动排除在Git版本控制之外
- 支持LAS和LIS通信原始数据记录

## 系统架构

采用模块化设计，各模块低耦合：
- **core**：核心模拟逻辑，处理设备状态管理和样本处理
  - 样本工作流管理
  - 设备状态管理
  - 库存管理
  - SQLite数据库持久化
- **las**：LAS 通信模块，实现 uRAP 协议服务端
  - TCP/IP服务器
  - uRAP协议解析和构建
  - 消息超时和重试机制
  - Keep-Alive心跳机制
- **lis**：LIS 通信模块，实现 ASTM 协议服务端
  - ASTM协议解析和构建
  - 工单查询和结果发送
  - 结果缓存机制
- **ui**：用户界面模块，提供图形化操作和监控
  - 主界面显示
  - 库存编辑器
  - 在机标本管理
  - LIS模拟界面
- **config**：配置管理模块，处理参数配置和持久化
- **logger**：日志模块，记录系统运行和通信日志
  - 系统运行日志
  - LAS通信日志
  - LIS通信日志
  - 原始数据日志
- **tests**：测试模块，包含所有测试文件和测试工具

## 配置

### 配置文件
系统使用 JSON 格式的配置文件，默认文件名为 `config.json`，包含以下主要配置项：

- **logger**：日志配置
- **las**：LAS 通信配置
- **lis**：LIS 通信配置
- **core**：核心模拟参数
- **test_inventory**：测试项目库存
- **consumable_inventory**：耗材库存

### 数据库
系统使用 SQLite 数据库进行数据持久化：
- **数据库文件**：`data/atellica.db`
- **on_board_samples 表**：存储在线样本信息
- **locked_carrier_info 表**：存储锁定的载具信息
- 应用启动时自动从数据库恢复样本数据
- 样本状态变更时自动同步到数据库

### 配置示例
```json
{
    "logger": {
        "level": "INFO",
        "console_output": true,
        "file_output": true
    },
    "las": {
        "host": "0.0.0.0",
        "port": 10001
    },
    "lis": {
        "host": "0.0.0.0",
        "port": 10002,
        "result_delay": 1800
    }
}
```

## 使用方法

### 启动模拟器

#### 有UI模式
```bash
python main.py
```

#### 无UI模式
```bash
python main.py --no-ui
```

#### 指定配置文件
```bash
python main.py --config my_config.json
```

### 命令行参数
- `--no-ui`：无UI模式运行
- `--config`：指定配置文件路径

### 主要操作

#### 有UI模式
1. **启动模拟器后，主界面显示设备状态和运行参数**
   - 顶部显示关键状态指标
   - 中间区域显示详细状态信息
   - 底部显示通讯日志

2. **参数配置**
   - 在"设备状态"选项卡中修改自动化接口状态、仪器处理状态、LIS连接状态
   - 修改IP0/IP1远程控制状态
   - 点击"应用"按钮生效

3. **在机标本管理**
   - 点击"在机标本"按钮打开标本列表
   - 查看当前在线标本的样本ID、状态和装载时间
   - 选择标本后点击"手工弹出"手动移除标本
   - 列表会自动刷新

4. **库存编辑**
   - 点击"编辑库存"按钮打开库存编辑器
   - 在"测试项目"选项卡中添加、更新、删除测试项目
   - 在"耗材库存"选项卡中管理耗材状态

5. **LIS模拟**
   - 点击"LIS模拟"按钮打开LIS模拟界面
   - 模拟LIS发送标本工单
   - 查看LIS通信日志

6. **通讯日志**
   - 在"通讯日志"区域查看LAS和LIS通信记录
   - 点击"清空日志"清除当前显示
   - 日志文件自动保存到`logs`目录

#### 无UI模式
- 后台运行，所有日志输出到日志文件
- 适合自动化测试和集成环境
- 可以通过日志文件监控系统运行状态

## 通信协议

### LAS 通信 (uRAP 协议)
- **监听端口**：默认 10001
- **协议类型**：TCP/IP
- **连接管理**：
  - 支持多客户端连接
  - 自动Keep-Alive心跳检测
  - 消息超时和重试机制
  - 连接断开自动恢复

- **支持消息类型**：
  | 消息类型 | 说明 |
  |---------|------|
  | Handshake | 握手协议，建立通信连接 |
  | Instrument Health | 仪器健康状态查询 |
  | Test Inventory | 测试项目库存查询 |
  | Onboard Sample Info | 在线样本信息查询 |
  | Consumable Inventory | 耗材库存查询 |
  | Transfer Status | 传输状态查询 |
  | Load/Unload | 装载/卸载请求处理 |
  | Add Queue | 添加队列 |
  | Skip Queue | 跳过队列 |
  | Clear Queue | 清除队列 |

### LIS 通信 (ASTM 协议)
- **监听端口**：默认 10002
- **协议类型**：TCP/IP
- **协议标准**：ASTM E1381/E1394

- **支持消息类型**：
  | 消息类型 | 说明 |
  |---------|------|
  | Query (Q) | 标本工单查询 |
  | Order (O) | 测试订单接收 |
  | Result (R) | 测试结果发送 |
  | Patient (P) | 患者信息 |

- **工作流程**：
  1. 接收LAS运送标本
  2. 向LIS查询测试工单
  3. 执行测试（模拟）
  4. 生成随机测试结果
  5. 发送结果回LIS

## 注意事项

1. **使用环境**：模拟器仅用于测试和开发环境，不得用于生产环境
2. **端口配置**：确保端口配置不与其他服务冲突
   - LAS默认端口：10001
   - LIS默认端口：10002
3. **日志管理**：定期清理日志文件，避免占用过多磁盘空间
   - 日志文件默认保留7天
   - 自动轮换机制
4. **数据安全**：
   - 配置文件中的敏感信息应妥善保管
   - 数据库文件`data/atellica.db`包含样本信息
5. **网络要求**：
   - 确保防火墙允许指定端口的TCP通信
   - LAS和LIS客户端需要能够连接到模拟器
6. **性能建议**：
   - 长时间运行时建议定期重启
   - 大量样本处理时关注内存使用情况
