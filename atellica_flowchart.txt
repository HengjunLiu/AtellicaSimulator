LAS 通信流程：
1. LAS → LAS模块：发送uRAP消息
2. LAS模块 → 核心模块：处理LAS请求
3. 核心模块 → LAS模块：返回处理结果
4. LAS模块 → LAS：发送uRAP响应

LIS 通信流程：
1. LIS → LIS模块：发送ASTM消息
2. LIS模块 → 核心模块：接收样本工单
3. 核心模块 → LIS模块：生成测试结果
4. LIS模块 → LIS：发送ASTM结果

UI 操作流程：
1. 用户 → UI模块：操作请求
2. UI模块 → 核心模块：更新设备状态
3. 核心模块 → UI模块：返回状态更新
4. UI模块 → 用户：显示结果
