# 各消息状态值：
## Instrument Health Response message
### Automation Interface Status：0x01 – Green， 0x03 – Red，0x04 – Critical
### Instrument Process Status：0x01 – Green，0x02 – Yellow，0x03 – Red  yellow和Red状态，对应很多种情况，模拟器直接固定成Green即可
### LIS Connection Status：0x01 – Connected，0x02 – Disconnected
### Interface Positions：SHC uses value 2
### Remote Control Status
	First Remote Control Status：0x01,0x04(IP0：0x01=Offline or Local/04=Online Loading Only Mode)
	First Lock Ownership：0x01，0x02(01=Locked by Instrument/02=Not Locked by Instrument)
	Last Remote Control Status：0x01，0x05(IP1: 0x01=Offline or Local/05=Online Unloading Only Mode)
	Last Lock Ownership：0x01，0x02(01=Locked by Instrument/02=Not Locked by Instrument)
